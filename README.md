# Probeklausur: Digitale Grundkompetenzen (Windows & Word)

Übungsversion der Klausur „Digitale Grundkompetenzen“. Oberfläche und Ablauf
sind identisch: Aufgabenliste, Timer, keine Erklärungen und keine
Rückmeldung während der Bearbeitung. Die Aufgaben sind **andere** als in der
echten Klausur, prüfen aber dieselben Fähigkeiten. Deshalb kann diese
Probeklausur schon jetzt öffentlich sein.

Unterschiede zur echten Klausur:

- 45 statt 90 Minuten, 9 statt 18 Aufgaben, 50 statt 100 Punkte
- kein Name, kein PDF-Bericht, kein Prüfcode, kein Fensterprotokoll
- direkt nach der Abgabe eine ausführliche Auswertung: Punkte, Note zur
  Orientierung und jedes Kriterium mit ✓ oder ✗
- beliebig oft wiederholbar („Probeklausur neu starten“), Auswertung druckbar

## Veröffentlichen

Alle Dateien liegen flach im Hauptordner. Über „Add file → Upload files“ ins
Repository hochladen und unter *Settings → Pages* „Deploy from branch → main →
/ (root)“ wählen. Dauer und Notenschlüssel stehen in `config.js`.

Die Simulationsdateien (`sim-*.js`, `util.js`, `style.css`) sind dieselben wie
in der echten Klausur. Die Aufgaben stehen in `aufgaben.js`.
